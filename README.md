## Important release condition

These drafts describe the audited local-first web runtime: no account, cloud database, advertising, analytics SDK, tracking, or developer-operated server was identified. Store purchase services may verify a purchase or entitlement when implemented in the native app.

The confirmed model is a limited Free Tier followed by a one-time, non-consumable Pro unlock on iOS that does not expire merely with time, and an auto-renewing Pro subscription on Android, with no advertising on either platform. Before making these pages effective or enabling them as store URLs, configure the exact products, Android billing interval, prices, and recurring value; compare the final signed Android App Bundle and iOS archive against `STORE-DISCLOSURES.md`; and resolve every item in `LEGAL-ALIGNMENT-AUDIT.md`. If the final build adds any SDK, permission, server, account, advertising, crash reporting, cloud backup, or different payment model, update the policies and store declarations before publication.
