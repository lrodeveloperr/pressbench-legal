# PressBench Legal & Support

Public legal and support documents for **PressBench** by GoodUse Studios.

Current Android release baseline: **1.0.0 — 24 August 2026**.

Public GitHub Pages routes, once Pages is enabled:

- Privacy: `/privacy/`
- Terms: `/terms/`
- Remove Ads / billing: `/subscriptions/`
- Safety: `/safety/`
- Local data and deletion: `/data-choices/`
- Support: `/support/`
- Third-party notices: `/third-party-notices/`

The canonical Android package is `com.goodusestudios.pressbench`.

The repository must remain publicly reachable for the privacy-policy URL to be usable in Google Play. Store declarations must always be rechecked against the exact signed AAB and current SDK versions before each release.
