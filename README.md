# PressBench Legal & Support

Public legal and support documents for **PressBench** by GoodUse Studios.

Current Android release baseline: **1.0.0-closed-v18-native (version code 1405) — 1 September 2026**.

Public GitHub Pages routes:

- Privacy: `/privacy/`
- Terms: `/terms/`
- Subscriptions and purchases: `/subscriptions/`
- Safety: `/safety/`
- Local data and deletion: `/data-choices/`
- Support: `/support/`
- Third-party notices: `/third-party-notices/`

The Android baseline contains no advertising SDK. Free users receive five successfully completed and saved runs; PressBench Pro is US$6.99 per month in the US storefront with Google Play geo-pricing and provides unlimited runs and PDF/CSV reports while active.

The canonical Android package is `com.goodusestudios.pressbench`. The repository and Pages site must remain publicly reachable. Store declarations must be rechecked against the exact signed AAB, Play Console configuration and current SDK disclosures before every release.
