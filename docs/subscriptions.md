# Purchases and Advertising Status

**Effective: 25 August 2026**

The reviewed PressBench Android `1.0.0-closed-v14` build does not include Google Mobile Ads, Google UMP or Google Play Billing.

## Current build

- The 320×50 banner area is an empty interface-inspection placeholder; it does not request or display an advertisement.
- **Privacy choices** displays an informational message only; it does not open Google UMP.
- **Remove Ads** changes a local test flag only; it does not open a Google Play purchase flow or create a charge.
- **Restore purchases** reads the local test flag only; it does not contact Google Play.
- **Manage subscription** displays a test message only; it does not contact Google Play.
- No PressBench subscription, renewal, cancellation or refund exists for this reviewed build.

Do not send payment-card details or purchase tokens by email. If a later production build activates advertising or a Google Play product, this page will be replaced with the exact product, benefit, renewal/cancellation, restoration and refund terms before that build is distributed.
